# Running Tests

Run the JavaScript helper regression tests with `npm run test:js` (Node.js 22).
These tests do not require a running WordPress site.

See [PHPUnit Docs](https://phpunit.readthedocs.io/en/9.5/textui.html) for all command line options

## Test Output
To see full test output, add the `--testdox` flag to `phpunit` command:

```
phpunit --testdox
```
